# Global-Healthcare-Resilience-COVID19-Data-Driven-Analysis (Tools: SQL, PowerBi)
A Data-Driven Assessment of Healthcare Capacity, Vulnerability, Response Capability and Pandemic Resilience.

Problem Statement:
Healthcare Systems across the world face a common challenge such as Disease outbreaks, limited Healthcare capacity and so on.
When the next health crisis hits, will healthcare systems be resilient enough to withstand pressure?

Objectives:
The objective of this analysis is to use data to better understand healthcare resilience, identify signs of system strain, and uncover insights that could support more informed decision-making.
